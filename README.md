# Task 6 - Dinesh Gallery

Made by **Dinesh Prasad** for the Web Development Internship.

## What is this?

A simple image gallery with 6 items. Each item has a picture and a caption.
The layout is made with CSS Grid: 3 columns on desktop, 1 column on mobile.

The picture is a colored box with an emoji, so no image files are needed.

## Files

- index.html - the gallery items
- style.css - the design and the grid
- script.js - counts the items and shows the number in the header
- profile.jpg - my photo

## How to run

Open the index.html file in a browser. Nothing else is needed.

## Made with

Simple HTML, CSS and JavaScript. No frameworks used.
